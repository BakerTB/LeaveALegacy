Chrome Ad Blocker
Extension

A Manifest V3 Chrome extension that blocks ad networks and YouTube ad requests at the network layer — before they even load. Built last summer after my brother couldn't find a free ad blocker that actually worked on YouTube.

🌿Why I Built This
→My brother was having a hard time finding a free ad blocker that worked consistently on YouTube — most either cost money, got patched out by Google, or required sketchy permissions.
→I wanted to understand how ad blockers actually work at the browser level — not just a filter list, but what API Chrome gives extensions to intercept network requests.
→Built last summer using Chrome's Manifest V3 extension system — the current standard that replaced Manifest V2 and how uBlock Origin and similar tools now work.
⚙️How It Works — declarativeNetRequest

Instead of injecting scripts that read and modify page content, this extension uses Chrome's declarativeNetRequest API — a declarative rule system where you define URL patterns and Chrome's network stack blocks matching requests automatically, before they ever reach a page.

→No page content access required: The extension only needs the declarativeNetRequest permission — it never reads, scans, or modifies any page's HTML or JavaScript. This makes it both safer and faster than content-script-based blockers.
→Host-level blocking: Rules target specific URL patterns (*doubleclick.net*, *googlesyndication.com*) and resource types (script, image, XHR, sub_frame). Matching requests return a network error before the browser even resolves DNS.
→Background service worker: The background.js service worker is minimal — it just confirms installation. All blocking logic lives in the declarative ruleset, not in runtime code.
🚫The 7 Blocking Rules
R1
*doubleclick.net*
Blocks Google's DoubleClick ad serving network — the infrastructure behind most display ads on the web. Targets scripts, images, XHR, and sub_frames.
R2
*googlesyndication.com*
Blocks Google AdSense/Syndication — the ad network that serves ads embedded in third-party websites. Same resource type coverage as R1.
R3
*youtube.com/get_video_info*
Blocks YouTube's video info endpoint used to fetch ad metadata before video playback begins. Interrupts the ad loading pipeline at the data layer.
R4
*youtube.com/api/stats/ads*
Blocks YouTube's ad impression tracking endpoint — the XHR that fires when an ad is viewed. Blocking this also interrupts the ad serving flow.
R5
*youtube.com/ptracking*
Blocks YouTube's ptracking endpoint used for ad engagement measurement. Part of the ad delivery verification chain.
R6
*youtube.com/generate_204*
Blocks YouTube's connectivity probe endpoint, which is reused by ad systems for ping-based tracking and ad completion signaling.
R7
*youtube.com/pagead*
Blocks YouTube's pagead endpoint — Google's primary page-level ad delivery route. Catches any remaining display or pre-roll ad load requests.
📄Extension Structure
manifest.json (key fields)
"manifest_version": 3
"permissions": ["declarativeNetRequest"]
"host_permissions": ["*://*/*"]
"declarative_net_request": { "rule_resources": [{ "id": "ruleset_1", "path": "rules.json" }] }
"background": { "service_worker": "background.js" }

Three files total: manifest.json (extension config), rules.json (7 block rules), background.js (service worker — 3 lines). Installed via Chrome's developer mode by loading the unpacked folder.

🔬What I Learned
Key Takeaway
The most interesting part was understanding why Manifest V3 exists — Google moved from MV2 (which allowed extensions to intercept all network requests with code) to MV3 (which only allows declarative, pre-auditable rules). This actually makes ad blockers more reliable in some ways but limits dynamic rule generation. The extension works — YouTube ads are blocked — but YouTube's anti-adblocker detection is a separate layer that targets page-level DOM changes, which this extension doesn't address.
