The Formula — Calls & Puts
European Call
C = S · N(d₁) − K · e^(−rT) · N(d₂)

European Put
P = K · e^(−rT) · N(−d₂) − S · N(−d₁)

Shared intermediates
d₁ = [ln(S/K) + (r + σ²/2)·T] / (σ·√T)
d₂ = d₁ − σ·√T

N(·) = cumulative standard normal CDF, implemented as 0.5 × (1 + erf(x / √2)). Assumes log-normal price distribution, constant volatility, no dividends, frictionless markets.

The Implementation
Black–Scholes.py (key logic)
import math

def N(x):
  return 0.5 * (1 + math.erf(x / math.sqrt(2)))

def black_scholes(S, K, T, r, sigma, option="call"):
  d1 = (math.log(S/K) + (r + 0.5*sigma**2)*T) / (sigma*math.sqrt(T))
  d2 = d1 - sigma * math.sqrt(T)
  if option == "call":
    return S*N(d1) - K*math.exp(-r*T)*N(d2)
  elif option == "put":
    return K*math.exp(-r*T)*N(-d2) - S*N(-d1)

# Example — ATM, 1yr, 5% rate, 20% IV:
black_scholes(100, 100, 1, 0.05, 0.2, "call") # → 10.45
black_scholes(100, 100, 1, 0.05, 0.2, "put") # → 5.57

The Five Inputs
S
Underlying Price
Current market price of the stock. Higher stock price → higher call value.
K
Strike Price
The price at which the option can be exercised. Further OTM → cheaper premium.
T
Time to Expiry
Measured in years. More time → more optionality → higher premium (theta decay).
r
Risk-Free Rate
Typically the 10-year treasury yield. Higher rates increase call values slightly.
σ
Implied Volatility
The most critical input — measures expected price uncertainty. Higher vol → more expensive options (vega).
What This Taught Me
→Model limitations matter: Black-Scholes assumes constant volatility — but in reality, IV changes continuously. The "volatility smile" is the market correcting for this assumption. A model price is a theoretical floor, not the truth.
→Pricing ≠ value: The formula gives you what an option "should" cost given the inputs. The gap between model price and market price is where real opportunity (or risk) lives — and understanding that gap is the whole point.
→You don't need NumPy for everything: Building N(x) from math.erf is a good reminder that Python's standard library is powerful — and keeping the implementation dependency-free makes it portable and educational.
