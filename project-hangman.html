A full Pygame Hangman game with a 2,986-word CSV word bank, custom word input, and a built-in solver that auto-plays using letter frequency. Started in Java, then rebuilt in Python with a drawn GUI.

Overview
→Started in Java as a terminal-based Hangman with text-drawn ASCII art figure and Scanner input — then rebuilt from scratch in Python with Pygame for a full graphical experience.
→The Pygame version draws the hangman figure procedurally using pygame.draw.line and pygame.draw.circle — gallows, rope, head, body, arms, legs, and X-eyes all drawn in code.
→Words are pulled from a 2,986-word CSV file at random each game. Up to 7 wrong guesses allowed before game over.
→The Options menu lets you switch to custom word mode — type in any word and pass the keyboard to a friend to guess. Supports spaces (multi-word phrases work too).
The Solver — Auto-Play Mode

The "Play Solver" button launches hangmanSolver() — an automated player that guesses letters one at a time and visualizes each step in real time at 500ms intervals so you can watch the strategy unfold.

→Strategy: Uses the hardcoded English letter frequency string "etaoinshrdlcumwfgypbvkjxqz" — guesses the most statistically common letters in English first, working through the alphabet by frequency rank.
→letter_tally(): The codebase also includes a function that counts actual letter frequency across all 2,986 words in the CSV — computing how often each letter appears in the specific word bank. This gives a game-specific frequency ranking vs. general English.
→Visual: The same displayHangman() function updates after each guess — you watch the figure build up in real time as the solver makes wrong guesses, making the strategy visible and stakes clear.
Java Version — Where It Started
→The original Hangman.java file runs entirely in the terminal. Takes a hardcoded word ("Hello"), prints ASCII art stages, and uses Scanner for letter-by-letter input.
→Supports 9 wrong guess stages (vs Python's 7) with progressively more detailed ASCII art — gallows → head → torso → left arm → right arm → left leg → right leg → expression.
→The Java version came first as a learning exercise in object-oriented design — the Hangman class encapsulates word state and the condition(String letter) method handles all matching logic.
